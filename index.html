Week 2

Question 1

Explain what is serverless architecture?

Answer

Serverless architecture is a model where the developer can focus purely on the application while the server is managed by a cloud service provider.

Question 2

When it is more feasible solution to use application containers (app virtualization) than full OS virtualization to provide networked services?

Answer

Containers are the feasible solution when you need smaller, more lightweight solution instead of a whole operating system. Several web services can run in separate containers on one host, sharing the host kernel while remaining isolated.

Question 3

List some information security risks when using third party (for example Docker) containers?

Answer

Risks include vulnerable or malicious images, outdated packages, leaked secrets, exposed ports, excessive privileges, host access, and attacks through untrusted dependencies.

Question 4

List requirements and features to be considered when estimating Amazon EC2 instance or Azure virtual machine deployment costs (check the pricing guides)

Answer

Things to consider when estimating EC2 or Azure virtual machine deployment price include: VM size, vCPUs, RAM, workload, operating system, runtime, storage, backups, data transfer, region, and discounts such as reserved instances or savings plans.

Week 3

Question 1

Describe reasons why so many (most?) companies are using cloud based email and calendar services

Answer

Cloud based calendar and email services can be accessed anywhere at any time. A cloud based calendar lets employees easily schedule meetings and events, and share them with eachother. Cloud based services are also often more secure than alternative solutions.

Question 2

Describe reasons, why many IoT devices (internet connected home appliances, Smart-TVs and such) are using Google's 8.8.8.8 or some other public DNS resolvers?

Answer

Many IoT devices use public DNS resolvers like Google's 8.8.8.8 because of their high reliability, performance and security. Local DNS servers are harder to maintain and may be less reliable, whereas public DNS resolvers are maintained by large organizations with enough resources to ensure uptime and security.

Question 3

Your thoughts about when to maintain your own web server and when to use SaaS/PaaS/IaaS to provide web services?

Answer

Maintaining your own web server is a good option when you want full control over the server or need custom configurations. Using SaaS/PaaS/IaaS is better when want to reduce maintanance and increase scalability. SaaS for ready-made applications, PaaS for custom applications without managing infrastructure, and IaaS for more control over virtual machines and networking.

Question 4

What would a mid-size company store to the Amazon Glacier? What not? Why? What other large cloud backup or mass storage providers are there?

Answer

A mid sized company would use amazon glacier for backups and data archiving purposes. Mainly for long-term storage of data that doesnt need to be accessed often. On the other hand, frequently accessed data would not be stored in amazon glacier because of its slow access times. Other large cloud backup or mass storage providers include Azure Blob Storage, Google Cloud Storage and Backblaze B2.
