Week 2 assignment

Question 1

Explain what is serverless architecture?

Answer

Serverless architecture is a model where the developer can focus purely on the application while the server is managed by a cloud service provider.

Question 2

When it is more feasible solution to use application containers (app virtualization) than full OS virtualization to provide networked services?

Answer

Containers are the feasible solution when you need smaller, more lightweight solution instead of a whole operating system. Several web services can run in separate containers on one host, sharing the host kernel while remaining isolated.

Question 3

List some information security risks when using third party (for example Docker) containers?

Answer

Risks include vulnerable or malicious images, outdated packages, leaked secrets, exposed ports, excessive privileges, host access, and attacks through untrusted dependencies.

Question 4

List requirements and features to be considered when estimating Amazon EC2 instance or Azure virtual machine deployment costs (check the pricing guides)

Answer

Things to consider when estimating EC2 or Azure virtual machine deployment price include: VM size, vCPUs, RAM, workload, operating system, runtime, storage, backups, data transfer, region, and discounts such as reserved instances or savings plans.
